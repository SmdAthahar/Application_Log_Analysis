# Application Log Analysis Using Python

## Project Description
This project demonstrates Python file handling by analyzing application log files. It reads log entries, counts INFO, WARNING, and ERROR messages, and separates them into individual files.

## Operations Performed
- Create and write application log entries.
- Read the entire log file.
- Count total log entries.
- Count INFO, WARNING, and ERROR occurrences.
- Extract ERROR messages into `errors.txt`.
- Extract WARNING messages into `warnings.txt`.
- Perform log frequency analysis using Pandas.
- Export log frequency results to CSV.

## Technologies Used
- Python
- Pandas

## Output Files
- `errors.txt`
- `warnings.txt`
- `info.txt` (optional)
- `log_frequency.csv`

## Objective
To understand Python file handling, text processing, and basic data analysis using Pandas.
